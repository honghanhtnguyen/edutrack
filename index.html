                              💾 Sao lưu & Đồng bộ

                              Dữ liệu app hiện lưu tạm trong phiên này. Xuất file JSON để giữ bản sao, hoặc đăng nhập Google bên dưới để đồng bộ qua Firebase.

                              Vào Firebase Console → Project Settings → General → Your apps → SDK config, copy nguyên đoạn code const firebaseConfig = {...} rồi dán cả cục vào ô dưới đây. Nhớ bật Authentication → Google và tạo Firestore Database trước nhé.
